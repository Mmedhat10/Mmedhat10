## A little about my work

I use Flutter and Dart to explore how mobile apps come together: the interface, the state behind it, and the services that power it. My public projects range from content readers and 3D exploration to apps that work with APIs and Firebase.

- **Interface:** reusable widgets, Material Design, navigation, and localization.
- **Application state:** Bloc/Cubit and Provider across different projects.
- **Connected data:** REST APIs, JSON models, authentication, and Firestore.
- **Current learning focus:** stronger Dart/OOP foundations, app architecture, and testing.

## Project collection

### 01 / Movies App
**Movie discovery with structured application state**

Browse and search movies, filter by genre, and open details and suggestions. The codebase includes account, watchlist, favourites, history, and profile flows, organized into feature modules with repositories and Bloc/Cubit.

`Flutter` `Bloc / Cubit` `Dio` `Firebase` `GoRouter`

[Explore Movies App →](https://github.com/Mmedhat10/Movies-App)

### 02 / Evently
**Events, preferences, and Firebase-backed data**

An event management project with event creation, editing, deletion, favourites, and account screens. Provider handles app state alongside Arabic/English localization and theme preferences.

`Flutter` `Provider` `Firebase Auth` `Cloud Firestore` `SharedPreferences`

[Explore Evently →](https://github.com/Mmedhat10/Evently_App-main)

### 03 / News App
**From a remote API to an article-reading interface**

A NewsAPI-powered project with category and source browsing, keyword search, paginated requests, cached images, and an embedded WebView for article content.

`Flutter` `HTTP` `REST API` `Provider` `WebView`

[Explore News App →](https://github.com/Mmedhat10/News_App-main)

### 04 / Islami App
**Local reading content with a personal reading history**

Quran and Hadith reading interfaces using bundled text assets, right-to-left Arabic content, and a digital Sebha. Recently opened surahs are saved locally with SharedPreferences.

`Flutter` `Provider` `Local Assets` `SharedPreferences`

[Explore Islami App →](https://github.com/Mmedhat10/Islami_App-main)

### 05 / Space App
**A closer look at planets through 3D**

A planet exploration interface combining local descriptions and facts with bundled 3D models, detail pages, and reusable presentation widgets.

`Flutter` `Dart` `3D Models` `flutter_3d_controller`

[Explore Space App →](https://github.com/Mmedhat10/Space_App-main)
